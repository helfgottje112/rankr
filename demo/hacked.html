🛡️ What Rankr found on this site

Platform: WordPress 6.4.2  (runs WORDPRESS)

Hack risk: HIGH

Why:

  • Login page (wp-login.php) fully exposed
  • XML-RPC endpoint open (no login required)
  • User list API returns admin usernames

What attackers could do:

DDoS amplification admin account enumeration credential brute-force malware & SEO spam defacement / ransomware
Suggested fix (free): put the site behind Cloudflare — hides wp-login behind an access rule, blocks XML-RPC floods, absorbs DDoS, adds free HTTPS. Try the live scan →
